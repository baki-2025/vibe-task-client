# Taskly

Taskly is a responsive micro-task and earning platform client for workers, buyers, and administrators.

## Features

- Animated responsive landing page with hero and testimonial sliders
- Top worker leaderboard and community content
- Email/password and Google sign-in interfaces
- Worker, buyer, and admin role-based dashboards
- Task discovery, task details, and submission workflow
- Paginated submission history
- Coin withdrawal requests with live dollar conversion
- Buyer task creation, review, update, and deletion interfaces
- Coin purchase packages and payment history
- Submission details and task update modals
- Admin statistics, withdrawals, users, and task management
- Floating notifications and persistent demo sessions
- Mobile, tablet, and desktop layouts

## Demo setup

Use the registration form to choose a worker or buyer role:

- Worker: 10 starting coins
- Buyer: 50 starting coins

The demo session is stored in browser local storage. Replace the client demo flows with your Firebase and MERN API as needed.

Copy `.env.example` to `.env.local` and add your environment values.

## Run locally

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
